# UniChat Widget - editableRaid

[🇺🇸 English](./README.md) | [🇧🇷 Português](./README.pt-br.md)

Este widget é o mesmo widget `raid` do [**UniChat**](https://codeberg.org/unichat/unichat), mas com a capacidade de editar seu código-fonte e com campos editáveis no editor.
